# 팀 선수 체중관리 앱 - 최종 배포 패키지

## 이것은 어떤 앱인가요?

- 학생선수 휴대폰: 아침/저녁 체중 입력
- 지도자: 전체 선수 기록, 미기록 현황, 평균, 그래프, CSV
- 푸시 알림: 미기록 선수에게 아침/저녁 알림
- PWA: 앱스토어 없이 휴대폰 홈 화면에 앱처럼 설치
- 회원가입 없음: 지도자가 만든 계정만 사용

## 가장 먼저 할 일

1. ZIP 압축 풀기
2. `DEPLOY.md` 열기
3. 서버 + 도메인 + HTTPS 준비
4. Docker Compose 실행
5. 지도자 로그인
6. 선수 계정 생성
7. 선수에게 로그인 정보 전달
8. 선수 휴대폰에서 팀 URL을 열고 홈 화면에 설치

## 테스트만 해보고 싶다면

Python 환경에서:

```bash
python -m venv .venv
pip install -r requirements.txt
flask --app app init-db
flask --app app run
```

단, `localhost` 테스트는 PWA 개발 테스트용이며 다른 휴대폰 팀원이 접속하는 실제 운영 주소가 아닙니다.

## 실제 운영 주소 예시

`https://weight.myteam.kr`

이 주소를 선수들에게 전달하면 됩니다.

## 보안

공개 회원가입을 제공하지 않기 때문에 관리자에게 등록받은 계정만 로그인할 수 있습니다.
선수는 자기 계정의 체중 데이터만 조회합니다.
